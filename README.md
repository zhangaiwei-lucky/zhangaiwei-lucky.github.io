# Aiwei Zhang · Academic Homepage

Personal academic homepage of Aiwei Zhang, built with React and Vite.

The site is based on the open-source template
[Anleeno/anleeno-academic](https://github.com/Anleeno/anleeno-academic)
(MIT License; the original copyright notice is kept in `LICENSE`).

## Develop

```bash
npm install
npm run dev
```

Content lives in `config/*.json`; images are in `src/assets/`.
See `config/README.md` for the editing guide.
